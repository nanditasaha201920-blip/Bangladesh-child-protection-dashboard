# 🇧🇩 Bangladesh Child Protection & Education Dashboard

An interactive data dashboard that provides insights into child protection and education indicators in Bangladesh using real data from UNICEF, World Bank, and BBS.

---

## 📊 Project Overview

This project analyzes key social indicators affecting children in Bangladesh, including:

- Child labour rates  
- Early marriage prevalence  
- Birth registration coverage  
- Children employment trends  
- Hazardous labour statistics  

The goal is to transform raw data into meaningful insights through an interactive dashboard.

---

## 🚀 Features

- 📈 Trend analysis over time  
- 📊 KPI metrics (latest indicators)  
- 🎯 Interactive filtering (year & indicators)  
- 🔍 Data exploration with charts  
- 🌐 Integration with World Bank API

## 📦 Installation

1. Clone the repository:

git clone https://github.com/your-username/bangladesh-child-protection-dashboard.git  
cd bangladesh-child-protection-dashboard  

2. Install dependencies:

pip install -r requirements.txt  

---

## ▶️ Run the App

streamlit run app.py
